# ⌨️ Xiong Terminal — 快捷键速查手册

> 基于 **Ghostty + Zsh** 终端环境，汇总所有插件/工具的 Top 3 常用快捷键。
>
> `super` = ⌘ Cmd | `alt` = ⌥ Option | `ctrl` = ⌃ Control | `shift` = ⇧ Shift

---

## 一、Ghostty（终端模拟器）

| # | 快捷键 | 功能 | 说明 |
|---|--------|------|------|
| 1️⃣ | **`Cmd+D`** | 向右新建分屏 | 最常用的分屏操作 |
| 2️⃣ | **`Cmd+Opt+↑↓←→`** | 在分屏间跳转 | 四方向随手切换 |
| 3️⃣ | **`Cmd+T`** | 新建标签页 | 轻量级多任务 |

### 补充

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `Cmd+Shift+D` | 向下新建分屏 | 横向布局 |
| `Cmd+Shift+Enter` | 放大/还原当前分屏 | 临时专注 |
| `Cmd+Shift+[/]` | 上/下一个标签 | 可盲打 |
| `Cmd+1~8` | 跳转到第 N 个标签 | `Cmd+9` = 最后一个标签 |
| `Cmd+Ctrl+方向键` | 调整分屏大小 | 步长 10 |
| `Cmd+= / Cmd+-` | 放大/缩小字体 | `Cmd+0` 重置 |
| `Cmd+↑/↓` | 跳转上/下一个命令提示符 | 在长输出中快速定位 |
| `Cmd+K` | 清屏 | 相当于 `clear` |
| `Cmd+Shift+,` | 重新加载配置 | 改完 Ghostty 配置立即生效 |
| `Opt+←/→` | 光标跳单词 | 配合 `Cmd+←/→` 跳行首/尾 |

## 二、Zsh 增强插件

### zsh-autosuggestions（灰色自动建议）

| # | 快捷键 | 功能 | 说明 |
|---|--------|------|------|
| 1️⃣ | **`→`（右方向键）** | 接受整条建议 | 最常用，一键补齐 |
| 2️⃣ | **`Ctrl+E`** | 跳到行尾兼接受建议 | 手指不离主键区 |
| 3️⃣ | **`Alt+→`** | 只接受建议的一个单词 | 部分采纳场景 |

> 灰色文字出现的瞬间直接按 `→` 或 `Ctrl+F`，养成肌肉记忆。

### zsh-syntax-highlighting（语法高亮）

- **无需快捷键** — 自动高亮合法命令（绿色）、非法命令（红色）、路径（下划线）
- 打字过程中实时反馈，拼错单词一眼就能发现

### zsh-completions（补全增强）

| # | 按键 | 功能 | 说明 |
|---|------|------|------|
| 1️⃣ | **`Tab`** | 触发补全 | 带描述菜单，比默认强 |
| 2️⃣ | **`Shift+Tab`** | 反向选择 | 在补全菜单往回走 |
| 3️⃣ | **`Enter`** | 选中当前项 | 或继续键入缩小范围 |

### History 前缀搜索

| # | 按键 | 功能 | 说明 |
|---|------|------|------|
| 1️⃣ | **`↑`（上方向键）** | 向上搜索历史 | 输入前几个字符再按 ↑ 效果最佳 |
| 2️⃣ | **`↓`（下方向键）** | 向下搜索历史 | 回到较近的命令 |
| 3️⃣ | **`Ctrl+R`** | 模糊搜索全部历史 | 由 fzf 或 atuin 提供，见下文 |

> 小技巧：先打 `git` 再按 ↑，只匹配 `git` 开头的历史命令。

## 三、fzf（模糊搜索神器）

| # | 快捷键 | 功能 | 说明 |
|---|--------|------|------|
| 1️⃣ | **`Ctrl+R`** | 模糊搜索命令历史 | 比 ↑ 遍历快无数倍 |
| 2️⃣ | **`Ctrl+T`** | 模糊搜索文件名 | 调用的 `fd`，忽略 .git |
| 3️⃣ | **`Alt+C`** | 模糊搜索目录并 cd | 配合 zoxide 效果更佳 |

### fzf 界面中的操作

| 按键 | 功能 |
|------|------|
| `Ctrl+J` / `Ctrl+K` | 上下移动（或 ↑↓） |
| `Ctrl+A` | 全选 |
| `Ctrl+D` | 取消全选 |
| `Tab` | 多选切换 |
| `Enter` | 确认选中 |
| `Esc` / `Ctrl+C` | 取消 |

## 四、zoxide（智能目录跳转）

| # | 命令/技巧 | 功能 | 说明 |
|---|-----------|------|------|
| 1️⃣ | **`z <关键词>`** | 跳转到匹配的目录 | 只输部分路径即可，如 `z proj` → `~/Desktop/main/projects/xxx` |
| 2️⃣ | **`z <A> <B>`** | 多关键词精确匹配 | 如 `z desk tools` → 含 desktop 和 tools 的目录 |
| 3️⃣ | **`zi`** | 交互式选择（调出 fzf） | 匹配结果太多时边搜边选 |

### 补充

| 命令 | 功能 |
|------|------|
| `z -` | 回到上一个目录（类似 `cd -`） |
| `z ` | 列出最高分目录列表 |
| `zoxide query <词>` | 只查不跳 |

## 五、atuin（增强 Shell 历史）

| # | 快捷键 | 功能 | 说明 |
|---|--------|------|------|
| 1️⃣ | **`Ctrl+R`** | 打开 atuin 历史搜索 | 全屏 TUI，支持模糊+语义搜索 |
| 2️⃣ | **`↑/↓`** | 在搜索结果列表中导航 | vs 传统 ↑ 不再乱跳 |
| 3️⃣ | **`Ctrl+E`** | 编辑选中的命令 | 执行前可修改 |

### 补充

| 快捷键 | 功能 |
|--------|------|
| `Enter` | 执行选中的命令 |
| `Ctrl+Y` | 粘贴选中的命令但不执行 |
| `Esc` | 退出搜索 |
| `/` | 在 atuin TUI 中按 `/` 进入搜索模式 |

> ⚠️ 注意：atuin 接管了 `Ctrl+R`，替代了 fzf 的历史搜索。如果你更习惯 fzf 的 `Ctrl+R`，可执行 `atuin disable-ctrl-r` 恢复。

## 六、bat（带高亮的 cat）

| # | 用法 | 功能 | 说明 |
|---|------|------|------|
| 1️⃣ | **`bat <file>`** | 带行号+语法高亮查看文件 | 替换 `cat`，自动检测语言 |
| 2️⃣ | **`bat -A <file>`** | 显示所有字符（含 tab/换行） | 调试空白符 |
| 3️⃣ | **`bat -l <lang> <file>`** | 强制指定语言高亮 | `bat -l yaml foo.conf` |

> 在 Pager（less）模式中：`j/k` 上下滚，`/` 搜索，`q` 退出。

---

## 七、eza（增强版 ls）

| # | 命令 | 功能 | 说明 |
|---|------|------|------|
| 1️⃣ | **`ll`** | 详细列表模式（已 alias） | 权限、大小、日期、Git 状态 |
| 2️⃣ | **`lt`** | 树形目录结构（已 alias） | `--level=2`，一眼看项目结构 |
| 3️⃣ | **`eza --tree --level=3 <目录>`** | 更深层级的树 | 默认 alias 只有 2 层 |

---

## 八、fd（飞快的 find）

| # | 命令 | 功能 | 说明 |
|---|------|------|------|
| 1️⃣ | **`fd <pattern>`** | 在当前目录递归搜索文件名 | 默认忽略 .git 和隐藏文件 |
| 2️⃣ | **`fd -e <ext>`** | 按文件扩展名搜索 | 如 `fd -e ts` 所有 TS 文件 |
| 3️⃣ | **`fd -t d <pattern>`** | 只搜目录 | `-t f` 搜文件，`-t l` 搜符号链接 |

---

## 九、ripgrep（飞快的 grep）

| # | 命令 | 功能 | 说明 |
|---|------|------|------|
| 1️⃣ | **`rg <pattern>`** | 搜索文件内容 | 默认递归、忽略 .git、二进制文件 |
| 2️⃣ | **`rg -l <pattern>`** | 只列出匹配的文件名 | 不显示具体匹配行 |
| 3️⃣ | **`rg -C 3 <pattern>`** | 显示匹配行上下 3 行上下文 | 调试代码很常用 |

## 十、btop（系统监控）

| # | 快捷键 | 功能 | 说明 |
|---|--------|------|------|
| 1️⃣ | **`M` → `P` → `D` → `N`** | 切换视图：内存 → 进程 → 磁盘 → 网络 | 四个主页面 |
| 2️⃣ | **`↑/↓`** | 在进程列表中上下选择 | 选中后可按 `Del`/`F9` 杀进程 |
| 3️⃣ | **`q` / `Esc`** | 退出 btop | |

> 按 `?` 或 `h` 查看全部快捷键。

## 十一、lazygit（Git TUI）

| # | 快捷键 | 功能 | 说明 |
|---|--------|------|------|
| 1️⃣ | **`Space`** | 暂存/取消暂存文件或区块 | 最常用的 Git 操作 |
| 2️⃣ | **`c`** | 提交（Commit） | 弹出 commit message 输入框 |
| 3️⃣ | **`p`** | 推送（Push） | 推送到远端 |

### 核心工作流

| 按键 | 功能 | 说明 |
|------|------|------|
| `←/→` | 切换面板 | Files → Branch → Commits → Stash |
| `Tab` | 切换上下分栏 | 文件列表 / 文件 diff |
| `↑/↓` | 在列表中移动 | |
| `s` | 暂存（Stage） | 与 Space 略有不同 |
| `S` | 暂存全部 | 全部文件一键暂存 |
| `d` | 丢弃/删除 | 未暂存的改动或文件 |
| `b` | 分支操作 | 切换/新建/合并 |
| `+/-` | 展开/折叠 diff | |
| `q` | 退出 lazygit | |
| `?` | 查看全部快捷键 | |

## 十二、fnm（Node 版本管理）

| # | 命令 | 功能 | 说明 |
|---|------|------|------|
| 1️⃣ | **`fnm install --lts`** | 安装最新的 LTS 版本 | 新机器第一件事 |
| 2️⃣ | **`fnm use <version>`** | 当前 Shell 切换版本 | 如 `fnm use 22` |
| 3️⃣ | **`fnm default <version>`** | 设置默认版本 | 新终端打开时自动使用 |

> 进入包含 `.node-version` 或 `.nvmrc` 的目录，fnm 自动切换版本（`--use-on-cd`）。

| # | 快捷键 | 功能 | 说明 |
|---|--------|------|------|
| 1️⃣ | **`q`** | 退出 diff 视图 | |
